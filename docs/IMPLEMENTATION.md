## 数据与时序

`SYSCFG_DL_init` 初始化外设，`main` 先屏蔽异步中断、停电机、初始化OLED和共享控制状态，再使能必要中断。主循环显示菜单并服务IMU；TIMA1为10ms控制基，TIMG6为1ms按键扫描。

编码器使用A/B完整Gray合法跃迁的净计数幅值，除以2并跨窗口保留余数，以匹配原双边沿标度。10ms反馈乘5维持原50ms参数尺度。这是速度幅值；方向不能仅靠该输出认定，需结合命令/诊断。A/B边沿及非法跃迁用于诊断，尖峰或中断风暴可以判窗无效。单相掉线可能使净计数接近零，由后级高PWM低速保护处理。

左右轮各有PI状态，位置误差转为轮速差。PWM硬上限1000；负的前进PI输出归零，不能作为反转驱动。底盘运输的共同加速/减速参数分别为2000ms/4000ms，默认值是源码配置，尚非当前硬件校准值。

## 源码修复

- 共用 `USART1/line_parser.h`，固定128字节容量（最大有效内容126字节，另留CR与结尾）。溢出或NUL丢弃到换行，合法后续帧可以恢复；仅接受完整CRLF和三个有界十进制整数。
- 原实时与非实时UART入口保留，避免256字节临时数据复制入128字节目标缓冲；默认固件UART0 RX仍关闭。旧备用入口不参与正常菜单调度。
- UART格式化改为 `vsnprintf`，去除复制的工具链 `stdarg.h`，使用标准头；保留单上下文共享TX缓冲约束。
- 修复 `uart0_send_string` 判空顺序、INT_MIN输出、中断屏蔽状态保存/恢复。TI Clang路径不使用旧ARMCC的FILE定义。
- PID对NaN/Inf参数或输入返回零并重置状态，后续有限输入可正常恢复；有限输入算法不改。
- 对可恢复的GB18030注释转UTF-8，对原本已经损坏的注释按代码重新表述；TI/LCKFB企业来源保留。

在WSL Ubuntu的GCC，以C11、`-Wall -Wextra -Werror -fsanitize=address,undefined` 执行：

```bash
bash tests/run_host_tests.sh
```

结果：串口CRLF/容量/超长/NUL/整数边界/恢复通过；真实PID源码的长序列饱和、前进不反转、位置死区、输出限幅与非有限输入恢复通过。测试未链接DriverLib、未编译主程序、未模拟中断与外设，不能证明固件整体可烧录或硬件安全。
